---
title: Add or edit a client
description: Learn what information you can keep in a client profile.
---

## Add a client

1. Select **Add client** next to **Clients**.
2. Enter the client's name.
3. Optionally add pronouns, country, email, phone number, WhatsApp, or Telegram.
4. Add a private note with any useful context.
5. Select **Add client**.

If a client with the same name or email already exists, Sessio will offer to open their profile. If the client is archived, Sessio will offer to restore it.

## Edit a client

Open the actions menu next to the client's name and select **Edit client**. You can update contact details and your private note at any time.

Email is used to match calendar events with the client. It is not required to record or upload a session.
