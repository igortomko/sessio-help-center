You can upload an existing recording to Sessio without microphone or Screen Recording access. MP3, M4A, and WAV audio files are supported.

## Where to find it

There are two ways to upload a recording: drag audio onto the client's **Files** tab, or start the upload from the **Start session** screen.

![Files tab: uploading an existing recording in Sessio](/images/client-files.png)

## How to do it

1. Open a client and go to the **Files** tab.
2. Drag an audio file in or select **Upload**.
3. Select **Create session**.
4. Set the meeting date. The date cannot be in the future.

## What you'll see

A new session with the chosen date appears in the client's history. Sessio prepares the transcript, summary, and note draft. The upload runs in the background — you can keep working.

## If it didn't work

If a format is not supported, use MP3, M4A, or WAV. If the upload was interrupted, select **Retry**. See [Upload and processing issues](/troubleshooting/processing) for more.
