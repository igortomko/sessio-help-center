---
title: Ask Sessio
description: How to ask a question about the content of a single session.
---

**Ask Sessio** helps you quickly find or gather information within the open session.

## Where to find it

Open a session and click **Ask Sessio**.

## How to do it

Ask a question about this session. For example, you can ask it to:

- briefly summarize the meeting;
- find agreements or homework;
- list the risks mentioned;
- describe the client's mood based on the recording.

## What you'll see

An answer based on the content of the open session. It may include links to the transcript so you can check the original fragment. Questions and answers are not added to the client's record and do not change the note or the summary — if you need the result in your work, copy it manually.

## If it didn't work

- **The answer looks incomplete.** Ask Sessio answers only about the open session. For the client's overall history, use the **Portrait** tab.
- **There is no data to answer from.** Make sure the session transcript is ready.

:::note
The answer applies only to the open session. For the client's overall history, use the **Portrait** tab.
:::
