---
title: Ask Sessio
description: Ask a question about the contents of one session.
---

**Ask Sessio** helps you quickly find or summarize information within the open session.

For example, you can ask it to:

- briefly summarize the meeting;
- find agreements or homework;
- list risks mentioned in the session;
- describe the client's mood based on the recording.

The answer may include transcript links so you can check the original segment.

Questions and answers from this window are not added to the client profile and do not change the note or summary. If you need an answer elsewhere, copy it manually.

:::note
The answer only uses the open session. For the client's broader history, use the **Overview** tab.
:::
