Start with the section that matches the issue. If the suggested steps don't help, report a bug through **Settings → Help**, and avoid pasting client names or note text into the description unless necessary.

- [Recording issues](/troubleshooting/recording) — recording doesn't start, a quiet microphone, the client can't be heard, an interrupted recording.
- [Upload and processing issues](/troubleshooting/processing) — a session doesn't upload or process.
- [How session processing works](/record-upload/processing) — what the processing statuses mean.
- [Permissions](/settings/permissions) — microphone and Screen Recording access.
