---
title: Getting started
description: Your first steps in Sessio, from adding a client to reviewing a completed note.
---

Work in Sessio starts with a client. You can then record a new session or upload an existing audio recording.

A typical workflow looks like this:

1. Add a client.
2. Record a session or upload a recording.
3. Wait for the transcript and session materials to be prepared.
4. Open the note, summary, or transcript.
5. Edit or export the text if needed.

The note draft is saved automatically. You do not need to approve or save it separately.

If you want to explore the app without using real data, open the sample client “Anna.” You can restore a deleted sample from **Settings → Help**.
