A client is the starting point in Sessio: sessions, notes, and files are all attached to one.

## Where to find it

The **Add client** button is in the sidebar (`⌘N`). You can edit the details later from the **⋮** menu next to the client's name.

## How to do it

1. Select **Add client** in the sidebar.
2. In the **Client name** field that appears, enter a name.
3. Select the pencil **Add details** to add pronouns, email, phone, WhatsApp or Telegram, and a private note.
4. Save the card.

![Quick add client in the Sessio sidebar](/images/add-client.png)

## What you'll see

The client appears in the sidebar list. Email is used to match calendar events with the client and is not required to record or upload.

## If it didn't work

If the name is already taken, Sessio warns you and offers to open the existing client, restore them from the archive, or create a new one anyway.
