---
title: How session processing works
description: Understand the statuses shown after recording or upload.
---

After recording or upload, Sessio uploads the audio, prepares the transcript, and assembles the session materials in turn. The status is visible in the client's session list.

## Where to find it

The processing status is shown next to the session in the client's session list and on the session page itself.

![The client's session list in the Sessions tab](/images/client-sessions.png)

## How to do it

Processing goes through several stages:

1. **Uploading audio** — the recording is being sent from your Mac.
2. **Preparing transcript** / **Transcribing** — the audio has been received and is being transcribed.
3. **Preparing draft** / **Analyzing** — Sessio assembles the session materials.
4. **Ready** — the summary, transcript, and note are available.

## What you'll see

When processing finishes, the transcript, summary, and note open. The note draft is saved automatically as soon as it is ready. Manual notes remain available even if transcription fails.

## If it didn't work

On failure, the status changes to **Processing error**, **Upload error**, or **Not processed**, and a **Retry** or **Process again** action appears.

:::note
You can retry processing while the source audio is still available. If it has already been deleted, Sessio will show that processing cannot be retried.
:::
