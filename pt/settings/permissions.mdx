title: macOS permissions
description: Why Sessio needs microphone and Screen Recording access and how to grant them.

To record sessions, Sessio uses macOS system permissions. They aren't needed to upload an existing audio file.

## Which permissions are needed

- **Microphone** records your voice.
- **Screen Recording** provides access to system audio — the client's voice from Zoom, Google Meet, and other apps. In the interface, this item is called **Call audio**.
- **Accessibility** synchronizes the recording controls with the active meeting window.
- **Notifications** let you know when the note is ready.

![Recording access screen: "Microphone" and "Call audio"](/images/macos-permissions.png)

## How to grant them

1. Open **Settings → Permissions**.
2. Select **Allow** next to the item you need.
3. If the system prompt doesn't appear, open **macOS System Settings → Privacy & Security** and enable access manually.

## If it didn't work

- **Sessio can't hear the client.** Screen Recording access hasn't been granted. Enable it and, if prompted, restart Sessio.
- **A quiet or empty microphone.** Check that the right microphone is selected, and switch the microphone mode in the panel menu to **Standard**.
- **The system prompt doesn't appear.** Grant access manually in macOS System Settings.
