---
title: Your first session
description: Add a client and generate your first note draft.
---

## 1. Add a client

Select **Add client** in the sidebar. Enter a name and optionally add contact details, pronouns, and a short private note about the client.

## 2. Choose how to create the session

- To record a new meeting, select **Start session** from the client profile.
- If you already have a recording, select **Upload session**, or drop an audio file into **Files** and choose **Create session**.

Recording requires microphone and Screen Recording access. These permissions are not required when uploading an existing file.

## 3. Wait for processing

After recording or upload finishes, Sessio prepares a transcript, summary, and note draft. You can follow the status in the client's session list.

## 4. Open the note

The note draft is saved automatically. You can open and edit it at any time; your changes are saved automatically too.

:::note
If processing does not finish, the session and your manual notes remain saved. You can retry processing while the source audio is still available.
:::
